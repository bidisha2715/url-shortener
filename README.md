# 🔗 URL Shortener

A full-stack URL shortener built using Flask and SQLite with REST APIs, click tracking, and analytics.

---

## 🚀 Live Demo
👉[ https://url-shortener-zj7s.onrender.com](https://url-shortener-1-f1ba.onrender.com)

---

## ✨ Features

- Shorten long URLs
- Redirect to original URLs
- Click tracking (analytics)
- REST API support
- Responsive UI

---

## 🛠️ Tech Stack

- Python (Flask)
- SQLite
- HTML, CSS, JavaScript
- Gunicorn (deployment)
