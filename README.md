# 🔗 URL Shortener

A full-stack URL shortening platform with user authentication, personalized dashboards, analytics, and a responsive UI built using Flask and SQLite.

---

## 🚀 Live Demo
👉[ https://url-shortener-zj7s.onrender.com](https://url-shortener-1-f1ba.onrender.com)

✨ Features
🔗 URL Shortening with unique short codes
✏️ Custom alias support for personalized links
🔐 User Authentication (Register/Login/Logout)
👤 User-specific Dashboard (view only your links)
📊 Link Analytics (click tracking and stats)
✏️ Edit short links (update alias)
🗑 Delete links with confirmation
📋 Copy-to-clipboard functionality
📱 Responsive design (mobile-friendly UI)
🎨 Clean and modern UI with structured layout
